# 📦 Vendor Performance Analysis

## 📌 Introduction

Analyzed vendor, brand, sales, margin, purchasing, and freight data to understand **supplier dependency, profitability, and potential supply-chain risks**.

## 🛠️ Technologies

Python · SQL · Power BI · Data Cleaning · Data Analysis

## ✨ Features

- Vendor purchase concentration analysis
- Brand profitability and sales-volume analysis
- Freight cost outlier analysis
- Bulk vs. non-bulk unit cost comparison
- Vendor and brand performance KPIs
- Interactive Power BI dashboard

## 🔄 Process

1. Cleaned and prepared vendor, brand, sales, margin, and freight data using Python
2. Used SQL to analyze vendor concentration and purchasing patterns
3. Compared brand margins against sales volume to identify growth opportunities
4. Investigated freight costs to identify potential logistics outliers
5. Compared unit costs across different order sizes
6. Combined the analysis into an interactive Power BI dashboard

## 📊 Results

- **Top 10 vendors contributed ~66% of total purchase dollars**, highlighting supplier dependency
- **135 brands** had good margins but low sales volume, creating potential growth opportunities
- Freight costs ranged from **$0.09 to ~$257K**, highlighting unusual costs for further investigation
- **Diageo** was the strongest vendor with approximately **$68.7M in sales**
- **Jack Daniel's No. 7 Black** generated approximately **$8.0M in sales**
- Bulk orders had the lowest average unit cost at approximately **$11.17**
